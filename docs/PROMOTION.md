# XingGou 星构工具箱宣传素材

## 标题

XingGou 星构工具箱｜把想法，搭成千星场景

## 简介

用本机浏览器，把千星奇域的现有原生资产搭成自己的场景。

XingGou 星构工具箱支持模型搜索与拖放、位置旋转缩放、多选组合、撤销重做。写下想法，先生成设计草案，再生成可继续编辑的布局；无需密钥也能先用离线规则模式，还可配置 OpenAI 兼容接口辅助设计。

已有完整原生资产优先使用，固定布景默认导出为静态 GIA；也能导出带材质 GLB，衔接 Blender。项目采用 GPL-3.0 开源，模型与贴图由使用者自行准备。

项目：<https://github.com/Crazyfourrrrrrrrrrr/XingGou>

下载与视频：<https://github.com/Crazyfourrrrrrrrrrr/XingGou/releases/tag/v0.2.0>
