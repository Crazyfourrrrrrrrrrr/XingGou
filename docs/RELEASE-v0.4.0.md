# XingGou v0.4.0 · 地编入门与 AI 协作

从一句想法开始，先确认玩家体验、概念与二维平面，再进入主体搭建和造景。此版新增内置教程与需求引导，完整包继续包含 2,996 个 GLB 模型、3,291 张内嵌图片、索引和官方 Windows x64 Python 运行时。

## 新增内容

- 顶部“地编教程”：可填写需求卡、查看下一轮问题、调用已配置 AI 分析文字需求、记录阶段确认、复制本阶段指令、下载需求卡与进度。
- 九阶段流程：需求分析 → 概念拆解 → 二维平面 → 主体与通行 → 地形 → 程序规则 → 远中近造景 → 氛围 → 性能实机。
- 网页 AI 助手先提问，再生成草案；需求卡未确认时先梳理缺项，二维平面未确认时提示先做规划。离线快捷布局继续可用。
- 外部 MCP 新增只读 `level_design_guide`；初始化指令要求先澄清需求，每轮问 2–3 个关键问题，确认平面后再写入场景。
- [使用教程](使用教程.md)、[AI 地编协作规范](AI地编协作规范.md)、[四合院完整案例](四合院示例.md)与二维占地/动线示例。

## 开始使用

Windows x64：下载 `XingGou-0.4.0-full.zip` 并完整解压，双击“启动星构.cmd”，再点页面顶部“地编教程”。先填已知信息，缺项让 AI 分轮提问；在“需求分析”勾选完成后采用需求。二维平面由你或外部 AI 画出并确认，在相应阶段勾选后重新采用需求，再生成三维布局。

`XingGou-0.4.0-source.zip` 是不含模型和 Python 运行时的单独源码版。完整包的 2,367 个模型已绑定游戏编号，其余可预览，GIA 导出前需确认绑定。详细说明见 [README](../README.md)。

## 制作边界

向导整理需求、问题与任务，不会自动雕刻千星地形、创建节点图或交互、写入游戏灯光、测量官方负载。二维规划符号不作为白模建筑导出。参考图片请交给支持视觉的外部 AI，本机兼容接口只接收文字。网页预览与游戏效果、文件检查与实机验收分别记录。

完整原生资产优先、固定布景独立静态导出和现有坐标转换继续沿用。原有工程、素材和配置兼容；升级时先备份自己的工程与配置，再使用新版本。旧版同时运行会占用另一个本机端口。
