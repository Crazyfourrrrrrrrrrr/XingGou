## 0.1.2：完整原生资产优先（2026-10-25）

默认离线与 AI 场景生成只接受可导出的完整原生模型，不用基元、白模或含基元的组合填补缺项。目录缺资源时列入 `notes`，由网页显示待补充内容；无真实模板编号的地块不猜测绑定。单个物件生成先检索现成资源，即使允许补充，有匹配模型仍优先使用；只有无匹配且 `allowPrimitives: true` 时才启用基元造型。

新版“溪畔小聚”V3 保留 V2 的 39 个建筑、树木和岩石，替换原来的桥、入口与摊位组合，移除 3 个白模基础面。现为 **47 个完整原生模型、0 个基元、0 个组合定义**，旧版为 92 个展开组件。此计数仅说明资产构成，**不能推导游戏官方负载或实际消耗**。

新增引用：木桥 `20002204 / Beyd_Gadget_Build_Qiao_04`、门楼 `20002217 / Beyd_Gadget_Build_Paifang_02`、摊位 `20001125 / Beyd_Gadget_Build_LowShop_01`、4 段石路 `20001073 / Beyd_Gadget_Build_RockRoad_03`、水体 `10005106 / Beyd_Gadget_Prop_WaterObject_Cube_01`。地面沿用游戏已有 Y=0 地形，不以白模基座替代。新建离线场景的 `settings.groundHeight` 默认 0；旧工程保留原高度，校准示例仍为 0.6。

水体 GLB 去掉已确认的外部提取样板根位置偏移，保留本体几何变换。网页材质为近似显示，不能证明原生水效果；深河道需在游戏原生地形工具中开挖。

```sh
python -m unittest discover -s tests -v
node tests/browser-smoke.cjs
blender --background --factory-startup --python tests/blender_verify.py -- <scene.glb> <report.json> <scene.blend>
```
