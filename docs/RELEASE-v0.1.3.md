# StarScene Studio v0.1.3

星构是本机运行的千星奇域场景编辑器：用已有完整原生模型布景，把文字转成设计草案与布局，导出 GIA 或带材质的 GLB。

## 本版重点

- **固定布景默认导出独立静态单位。** 工程分组展开后，每个模型保留自己的世界位置、旋转和缩放，无动态父实体、无父级 0.01 缩放补偿。旧动态编码路径保留兼容读取，网页和 MCP 默认使用静态格式。
- **现成原生资产优先。** 默认布局只用可导出的完整原生模型。缺资源列出缺项，不自动用白模拼搭；单个新造型仅在无匹配且明确允许时启用基元补充。
- **可在外部继续设计。** 支持搜索、拖放、变换、多选组合、撤销重做、工程自动保存、GLB 导出和 stdio MCP。
- **文字到场景。** 同时提供无密钥的离线规则布局和 OpenAI 兼容接口，草案可编辑后再生成场景。
- **易辨认的导入名称。** 类型、版本置于文件名和物件名前部，例如 `静态V4·溪畔小聚.gia`、`静V4·木质房屋 1`。

## 实际验证

2026-10-25，测试者实际导入静态 V4“溪畔小聚”后确认“负荷正常了”。场景包含 47 个完整原生模型、0 个基元。没有新的区域负载数值，不计算具体节省比例。本次反馈没有新增材质、精确 TRS、碰撞或多个静态单位批量操作的专项证据。

静态导出主变更完成时，33 项 Python 单元与集成测试通过；隔离浏览器回归通过，0 个非预期错误。后续命名修复未重跑整套测试。0.1.2 的 GLB 曾在 Blender 5.2.2 LTS 独立导入，36 张贴图全部内嵌且有效；它是历史 GLB 验证，不等于静态 GIA 的专项验收。

详见[验证记录](VALIDATION.md)。

公开发布前，还在无外部资产库的干净源码副本中运行了全部 33 项测试：22 项通过、11 项真实资产集成测试明确跳过。新增 GitHub Actions 覆盖 Linux/Windows 与 Python 3.10/3.12；远端运行结果以仓库 Actions 为准。

## 运行与资产

在 Releases 下载 `StarSceneStudio-0.1.3-source.zip`，解压后按 README 配置并启动。`SHA256SUMS.txt` 提供下载文件的校验值。

需要 Python 3.10+、支持 WebGL 2 的现代浏览器，以及使用者自己准备的本地资产库。配置后运行：

```sh
python launch.py
```

源码不附游戏模型、贴图或完整资产目录；不会自动下载缺失资产。GIA 需要模型与真实原生模板编号正确对应。安装及资产索引示例见 [README](../README.md)。

## 更新注意

此前版本的动态父实体导出不适合本项目的固定布景目标。已有 `.starscene.json` 可继续编辑并重新导出；静态版不再提供统一父实体，不要沿用旧版父级缩放操作。替换测试场景时避免同时保留新旧副本，以便判断实际效果。

浏览器水体和专有着色器可能近似显示；本版不上传任意外部网格为新模板，不生成运动、交互或节点图。AI 兼容接口已用模拟 HTTP 服务验证，具体模型服务需另行配置与验证。
